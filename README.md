# LocalTTS Studio

Полностью локальная, офлайн студия озвучивания для Windows. Заточена под
**русскую** речь для YouTube.

- **Движок:** Qwen3-TTS 1.7B (Alibaba, Apache-2.0) — клонирование голоса из
  короткой записи (15–45 с) + её расшифровки. Один движок, без переключений.
- **Интонацию задают пресеты**, а не команды в тексте. 10 готовых:
  Обычный · Нормальный · Радостный · Грустный · Шёпот · Злой · Взволнованный ·
  Саркастичный · Флирт · Документальный.
- **Нормализация текста** офлайн: `C++` → «си плюс плюс», `15:30` → «пятнадцать
  часов тридцать минут», `2026 год` → «две тысячи двадцать шестого года`. В
  редакторе виден исходный текст, Qwen получает нормализованный.
- **Несколько вариантов за раз** (ползунок 1–5 в «Ещё»): N независимых генераций
  одного текста — слушаете и выбираете лучшую.
- **Ничего наружу:** после установки работает с выключенным интернетом.

---

## Запуск

```
setup.bat
```

Один раз, с интернетом. Создаёт `runtime\`, ставит PyTorch (CUDA если есть GPU),
качает веса Qwen (~4.6 ГБ в `models\qwen-1.7b\`), делает стартовый голос и
офлайн self-test.

**Двойной клик по `LocalTTS.bat`** (или `run.bat`) — откроется браузер на
<http://127.0.0.1:8765>. Закрыть окно консоли (или Ctrl+C) — остановить.
Ярлык на рабочий стол: двойной клик по `Создать ярлык на рабочем столе.bat`.

| | |
|---|---|
| ОС | Windows 10/11 (64-бит) |
| Python | 3.12 (или 3.11–3.13), python.org |
| GPU | NVIDIA ≥8 ГБ VRAM. На CPU работает, но ~в 5 раз медленнее realtime. |
| Диск | ~9 ГБ |
| FFmpeg | не нужен — встроен через `imageio-ffmpeg` |

> Не держите папку в `Downloads\` — Windows Storage Sense может её удалить.
> Перенесите в `C:\Users\<вы>\LocalTTS`.

## Как пользоваться

1. **Голос.** Нажмите **＋** рядом с «Голос». Загрузите один клип **или несколько
   коротких** (15 с и т.п. — склеятся по порядку). Форматы: MP3, WAV, M4A, FLAC,
   OGG, Opus. Впишите **расшифровку** — ровно то, что произносится (обязательно).
   ⚙ у голоса — редактировать название / пол / язык / расшифровку. Загрузка с тем
   же ID **всегда** заменяет старый голос.
2. **Пресет.** Выберите интонацию. Подсказка под названием.
3. **Сценарий.** Вставьте текст. Команды не нужны. Пустая строка = пауза между
   абзацами. Ударение — плюс перед гласной: `проц+ессор`. Частые сокращения
   (`комп` → `ко́мп`) правятся автоматически.
4. **Проверить текст** — анализатор найдёт латиницу вне словаря, английские
   предложения, слишком длинные предложения, слова без гласных, отсутствие точки.
   «Применить автоисправления» — впишет в текст нормализованный вариант (цифры
   словами, термины из лексикона). Ударения из `stress.dictionary` применяются
   автоматически при каждой генерации, отдельная кнопка не нужна.
5. **Озвучить.** Во вкладке «Ещё» — «Количество вариантов» (1–5). При 1 —
   обычный один результат. При 2–5 — список карточек «Вариант N» с плеером,
   «Скачать MP3», «WAV» и «Выбрать этот» (делает вариант основным + копия в
   `projects\workspace\final\`). Прогресс показывается как «генерация 2 / 5»;
   ошибка одного варианта не отменяет остальные.
6. **История** справа — прошлые генерации, прослушать / оставить.

Файлы: `projects\workspace\generations\<время>\variant_<n>\`
(raw.wav, final.wav, final.mp3) + `report.json` (исходный/нормализованный текст,
параметры Qwen, план пауз, сиды вариантов) + копия первого варианта в `output\`.

## Пресеты

`config\config.json → presets`. Каждый пресет — три развязанных группы:

```json
"радостный": {
  "label": "Радостный", "order": 3, "hint": "энергично, с улыбкой",
  "generation": { "temperature": 0.95, "top_p": 1.0, "repetition_penalty": 1.03 },
  "prosody":    { "pause_scale": 0.82, "jitter": 0.22 },
  "audio":      { "gain_db": 0.5 }
}
```

Эмоция задаётся **параметрами генерации Qwen + политикой пауз**, а не
питч-шифтом и не растяжением. `audio` — минимальная правка (обычно только
`gain_db`, для шёпота ещё `eq`). Питч-шифта в пайплайне нет.

## Ударения и произношение

- `+` перед гласной → эта гласная получает знак ударения (U+0301), который
  Qwen учитывает: `в+ажно`, `проц+ессор`.
- Словарь частых замен: `config\config.json → stress.dictionary`
  (`"комп": "к+омп"` и т.п.). Анализатор применяет его в «автоисправлениях».
- Латиницу в русском тексте лучше писать кириллицей — анализатор подсветит.

## Офлайн

`config\config.json → "offline_mode": true` (по умолчанию). В рантайме:
`HF_HUB_OFFLINE=1`, блокировка всех не-loopback сокетов (`app/netguard.py`),
никаких скачиваний. Проверка:

```
run.bat --selftest
```

Только `setup.bat` требует интернет.

---

## Перенос на другой ПК

Скопируйте всю папку `LocalTTS\` (можно без `runtime\`), запустите `setup.bat`.
`models\`, `voices\`, `projects\`, `config\`, `output\` едут с папкой.

## Калибровка

```
python -m scripts.calibrate_tts --voice asii --grid coarse
python -m scripts.calibrate_tts --dry-run          REM только план, без модели
```

Грид-поиск по `temperature` / `top_p` / `repetition_penalty` на наборе
эталонных текстов (техника, числа, вопрос, восклицание, разговор, эмоция,
длинный). Детерминированный сид. Пишет аудио + `results.json` + `README.md` в
`calibration\<время>\`. **Ничего не применяет к `config.json`** — послушайте и
перенесите победившие числа в пресет вручную.

## Разработка

```
test.bat                     REM 123 теста
python -m scripts.check_env  REM отчёт по железу и установке
run.bat --selftest           REM офлайн: реальный Qwen, мульти-вариант, EN/RU
```

| модуль | назначение |
|---|---|
| `app/text_normalizer.py` | офлайн-нормализация: лексикон произношения, числа, даты, время, %, акронимы |
| `app/prosody.py` | нормализация → ударения → семантические чанки → контекстные паузы → `[Segment]` |
| `app/analyze.py` | анализатор текста + автоисправления (обёртка над нормализатором) |
| `app/pipeline.py` | N вариантов × (чанки → Qwen ICL → склейка+паузы → мастеринг → WAV/MP3) + `report.json` |
| `app/audio.py` | тишина / gain / EQ / loudnorm / limiter / один глобальный time-stretch под слайдер скорости |
| `app/voices.py` | реестр голосов; склейка нескольких клипов; add/update/delete |
| `app/tts/qwen_engine.py` | обёртка Qwen3TTSModel; `torch.manual_seed` под вариант; кэш clone-prompt |
| `app/server.py` | Flask + JSON API; `/api/generate` → job_id, `/api/generate/status/<id>` поллинг |
| `scripts/calibrate_tts.py` | офлайн грид-поиск параметров генерации |
| `launcher.py` | EXE: проверка железа/модели → сервер → браузер → чистая остановка |

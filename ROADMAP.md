# LocalTTS Studio — roadmap

## Сделано

- [x] Один движок: **Qwen3-TTS 1.7B**, `transformers==4.57.3` (жёстко). Chatterbox,
      Kokoro, переключение движков, создание проектов — вырезано.
- [x] Русский по умолчанию; UI на русском.
- [x] Команды в тексте убраны — интонация только через **10 пресетов**
      (Обычный / Нормальный / Радостный / Грустный / Шёпот / Злой / Взволнованный /
      Саркастичный / Флирт / Документальный).
- [x] Пресет — три развязанных группы: `generation` (temperature/top_p/rep_penalty),
      `prosody` (pause_scale/jitter/trail_ms), `audio` (gain_db/eq). Эмоция через
      параметры Qwen + паузы, **без питч-шифта и растяжения**.
- [x] **Нормализатор текста** (`app/text_normalizer.py`), офлайн: лексикон
      произношения (C++→«си плюс плюс», JavaScript→«джаваскрипт», …), числа,
      десятичные, проценты, даты, время, деньги, годы (родительный падеж),
      диапазоны, порядковые, акронимы по буквам. Английские предложения не
      русифицируются. `original_text` и `normalized_text` хранятся отдельно —
      редактор показывает исходный, Qwen получает нормализованный.
- [x] **Семантические чанки**: Qwen вызывается на крупных кусках (целые абзацы,
      когда влезают), а не по предложению — сохраняется просодическая связность.
      `C++ разработчик`, `двадцать три градуса` не разрываются.
- [x] **Контекстные паузы**: только на структурных границах (абзац / вынужденный
      разрыв), масштаб от пресета + сид-джиттер. Внутри чанка тишина не вставляется.
- [x] **Мульти-вариант**: ползунок «Количество вариантов» 1–5 в «Ещё». N
      независимых стохастических генераций (один голос/эмоция/текст, разные сиды).
      Вкладка «Результаты» со списком карточек, «Выбрать этот», прогресс,
      устойчивость к падению одного варианта. Модель и clone-prompt переиспользуются.
- [x] Фоновая задача: `/api/generate` → `job_id`, `/api/generate/status/<id>` поллинг.
- [x] `report.json` на каждую генерацию: исходный/нормализованный текст, замены,
      параметры генерации, план пауз, сиды и длительности вариантов, пост-обработка.
- [x] Детерминизм: `torch.manual_seed` + `torch.cuda.manual_seed_all` перед каждым
      вариантом (в Qwen API нет нативного параметра сида).
- [x] Калибровочный CLI `python -m scripts.calibrate_tts` — грид-поиск
      temperature/top_p/repetition_penalty на эталонных текстах,
      детерминированный сид, пишет в `calibration/<время>/`, **не трогает** config.
- [x] Ударения: `+гласная` → U+0301; словарь частых слов в config.
- [x] Анализатор текста: латиница вне лексикона, английские предложения, слова без
      гласных, длинные предложения, отсутствие финальной пунктуации +
      «Применить автоисправления».
- [x] Голоса: несколько коротких клипов склеиваются; **всегда перезапись** по ID;
      кнопка ⚙ — редактирование метаданных/расшифровки; фикс бага с кэшем
      (ключ = файл+mtime+текст); поддержка MP3/M4A/FLAC/OGG/Opus на загрузке.
- [x] Визуал в стиле Claude (тёплый фон, коралловый акцент, карточки).
- [x] Один рабочий проект `workspace`; `LocalTTS.bat` + ярлык на рабочий стол.
- [x] 123 теста + офлайн self-test на реальном Qwen (`run.bat --selftest`).
